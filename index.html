Videasy is the main server and works well for everything -- start there. TryEmbed (Sub)/(Dub) is anime-only, so it won't work for regular movies or shows; try it specifically if Videasy's audio or subtitles aren't right for a particular anime. Videasy runs with no iframe sandbox at all (needed for its player to function), so it can technically open a stray pop-up or redirect on its own, though this has only been seen rarely, not constantly. TryEmbed runs with a wider-but-still-protective sandbox that blocks pop-ups outright. Picture quality varies by title and server -- try switching if one looks soft.
